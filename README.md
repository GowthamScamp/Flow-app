# Flow

**Flow is a local-first AI workspace for your Windows desktop.** Chat with AI, work on code, and research questions in one app. Run models on your own computer with Ollama, or in the cloud with OpenRouter.

**Version 2.1.3** · Windows · **Free to use**

## Three modes

Flow has three modes. Each one has its own colour, so you always know where you are.

| Mode | What it's for |
| --- | --- |
| **Chat** | Think out loud, draft, and explore ideas. |
| **Code** (Coding Assistant) | Explore, edit, run, and verify projects. |
| **Research** (Research Assistant) | Investigate questions, evaluate sources, and create reports. |

---

## Connect a model

Flow works with two kinds of model. Pick the one that suits you, or set up both.

- **Ollama: on your computer.** Local and private. Models run on this computer, and you choose from the models you have installed.
- **OpenRouter: in the cloud.** One API key gives you access to many models. The key is stored in your operating system's credential store.

You can skip this step during setup and configure a model later in **Settings**.

## Features

### Chat

- A **Think** toggle shows the model's reasoning in a collapsed **Thought** card. It stays separate from the answer.
- Answers render headings, lists, code blocks and tables.

### Code

- The agent reads and searches your project, then proposes edits.
- **Every edit needs your approval.** A "Review needed" dialog offers **Approve**, **Reject**, **Approve this turn** and **Allow for this session**.
- Accept or reject each change in the diff.
- Revert changes file by file, or roll back a whole turn.
- A **code graph** maps your project as an interactive map.

### Research

- Flow searches the web, reads the sources, and writes an answer in which **every claim cites its source**.
- Cited claims are **checked automatically** against the sources they cite. The app shows the result, for example: "Checked automatically: 3 of 3 cited statements match the evidence they cite."
- Export reports as **MD, HTML, PDF and DOCX**, and citations as **BIB and RIS**.

### Also

- A command palette.
- A Settings screen with a Models section.
- Light and dark themes.
